# Chess Coach

A browser chess trainer for club players (roughly 800–1600) who know the rules and the opening moves but get stuck once the opening ends. It focuses on what actually decides games at that level: hung pieces, missed tactics, and not knowing what to do next.

Everything runs in the browser. Stockfish 19 is compiled to WebAssembly and runs in a Web Worker, so there is no server and no account.

## What's in it

**Play with a coach.** Play the computer at any strength from 100 to 3000 Elo. In coach mode every move is graded (brilliant, great, best, excellent, good, inaccuracy, mistake, missed win, blunder) and explained in plain English: "your knight on f6 is hanging", "this walks into a fork", "you missed mate in 2". On a mistake the coach pauses so you can take the move back. There's also a blunder-check button that lists what's under attack and which checks your opponent has, plus two-step hints.

Below 1320 Elo the bot simulates a human: it samples from Stockfish's top moves with an Elo-dependent temperature and sometimes plays a "tempting" random move. From 1320 up it uses Stockfish's own strength limiter.

**Learn.** 14 lessons on the blunder check, loose pieces, forks, pins and skewers, discovered attacks, mating patterns, what to do after the opening, plans from pawn structure, attacking the king, trading, converting, defending, endgames, and thinking during a game. Exercises are engine-judged, so any equally good move counts. A wrong answer gets the coach's explanation of why it fails.

**Openings.** A 1.e4 White repertoire built around the Ruy Lopez, the Alapin against the Sicilian and the Advance against the French and Caro-Kann. For Black, a low-theory setup: 1...e5 against 1.e4, and ...d5/...e6 against everything else. Every move has a note, and every line ends with the middlegame plan. Drill mode plays random lines and brings up the ones you get wrong more often.

**Puzzles.** An offline pack generated by this repo's own script, plus unlimited online puzzles from the Lichess puzzle API, by theme and difficulty. Puzzles have their own rating and streak.

**Review.** Import your games from chess.com by username, or paste a PGN. You get an evaluation graph, per-move grades and explanations, accuracy, and key moments. "Retry this moment" turns a mistake into a puzzle. The dashboard aggregates your mistake types across games (walked into forks, ignored threats, missed free pieces…) and links each one to the lesson and puzzle theme that fixes it.

## How the coach explains moves

`src/lib/coach.ts` grades with the win-probability curve Lichess uses, then runs rule-based detectors on the engine's lines:

- allowed or missed mate
- hanging pieces (undefended, or attacked by something cheaper)
- moving a defender away
- ignoring an existing threat
- losing exchanges
- forks, pins, skewers and discovered attacks, both allowed and missed
- missed free material
- opening principles (early queen moves, edge pawns, moving the same piece twice)
- positional fallbacks (castle, develop, fight for the centre)

## Content is verified

Nothing is taken on trust:

- `npm run test:coach` runs the explanation engine against real Stockfish on known positions: Scholar's mate, the Blackburne Shilling trap, the Fried Liver fork, and others.
- `npm run verify` checks every lesson position, exercise solution and repertoire line with Stockfish at depth 18. It fails if a "solution" isn't actually good, a FEN is illegal, or a repertoire move is a real mistake. `verify:quick` is the fast version that CI runs.
- `npm run puzzles` regenerates the offline puzzle pack. It plays engine games between human-like bots and keeps positions with a unique winning move, then re-checks every solver move for uniqueness.

## Run it

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # static site in dist/
```

Pushing to `main` runs the tests, verifies the content, builds the site and deploys it to GitHub Pages (Settings → Pages → Source: GitHub Actions).
